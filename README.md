# Анализ пользовательских отзывов Amazon

## О проекте

Проект посвящен исследованию пользовательских отзывов на товары Amazon с применением методов анализа данных и обработки естественного языка (NLP).

Основная цель работы — определить общее отношение пользователей к продуктам, выявить наиболее обсуждаемые темы, найти причины негативных оценок и сформулировать выводы, которые могут быть полезны при развитии продукта.

---

## Цели исследования

В рамках проекта решались следующие задачи:

- провести предварительный анализ данных;
- подготовить текстовые данные к анализу;
- исследовать распределение пользовательских оценок;
- выполнить анализ тональности отзывов;
- определить наиболее часто встречающиеся темы;
- выявить ключевые причины положительных и отрицательных отзывов;
- сформулировать практические выводы на основе результатов анализа.

---

## Используемые данные

Для анализа использован датасет отзывов Amazon.

Исследуемые данные включают:

- рейтинг пользователя;
- текст отзыва;
- информацию о товаре;
- дополнительные служебные признаки.

---

## Ход исследования

### 1. Первичный анализ данных

На данном этапе выполнены:

- изучение структуры датасета;
- проверка типов данных;
- поиск пропусков;
- анализ распределения основных признаков;
- удаление некорректных записей.

---

### 2. Предобработка текста

Перед выполнением анализа отзывы были очищены и нормализованы.

Выполнены следующие операции:

- перевод текста в нижний регистр;
- удаление знаков пунктуации;
- удаление стоп-слов;
- лемматизация;
- очистка специальных символов.

---

### 3. Исследовательский анализ данных (EDA)

Проведен анализ:

- распределения пользовательских оценок;
- длины отзывов;
- наиболее часто встречающихся слов;
- взаимосвязей между признаками.

Для визуализации использовались различные графики и диаграммы.

---

### 4. Анализ тональности

Исследовано соотношение положительных и отрицательных отзывов.

В ходе анализа определены:

- общий уровень удовлетворенности пользователей;
- влияние рейтинга на эмоциональную окраску текста;
- характерные слова для различных категорий отзывов.

---

### 5. Тематический анализ

Для выявления основных направлений обсуждения применены методы тематического моделирования.

Это позволило определить наиболее значимые темы отзывов и понять, какие аспекты продукта пользователи обсуждают чаще всего.

---

## Основные результаты

В результате исследования удалось:

- оценить распределение пользовательских оценок;
- определить общее настроение отзывов;
- выявить наиболее обсуждаемые темы;
- найти основные причины негативных отзывов;
- выделить сильные стороны продукта;
- получить практические рекомендации на основе анализа данных.

## Итог

Работа демонстрирует применение методов анализа данных и NLP для исследования пользовательских отзывов. Полученные результаты позволяют не только оценить общее отношение пользователей к продукту, но и выявить конкретные направления, требующие улучшения.
